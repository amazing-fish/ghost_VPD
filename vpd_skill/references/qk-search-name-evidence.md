# QK-230 工作机取证：名称检索和编号展示

OneBox 第 59 行的期望是“搜索成功，显示结果”。本轮先问两个问题：实际输入这个名称后，结果里出现了哪一行？该行是否确实是事先选定的收藏对象？编号另外记录。车位和路点各填一次，有一边缺证据也能保留另一边的观察。[原表追溯](https://github.com/amazing-fish/ghost_VPD/issues/106#issuecomment-6431475672) · [路点编号争议](https://github.com/amazing-fish/ghost_VPD/issues/108)

## 现场操作

1. 使用验收时最新 PR 代码，记录 SHA、APP 版本、设备形态、所在园区与本轮会话 ID。分别选一条已收藏车位和路点，名称可以自行设置。先在收藏管理页或对应卡片的 `⋮` 信息面板核对收藏归属、对象类型、完整名称及可区分对象的属性，记下源观测 ID。以前这条路径读到过车位编号，另一个对象只有楼层，当前版本还需重走；点卡片名称进入的算路面板是另一个入口。首页“常去地点”混有默认项，单独读到其名称只能用作查询值线索。[历史收藏面板](https://github.com/amazing-fish/ghost_VPD/issues/111#issuecomment-6682208589) · [本轮工作机记录](https://github.com/amazing-fish/ghost_VPD/issues/65#issuecomment-6973793842)
2. 搜索一个对象，用 `observe` 保存结果稳定后的树和截图，记录结果观测 ID。另一对象单独采集。输入残留、弹窗或页面结构变化时，保留第一次观测并报告实际差异。原件留在工作机，本轮只提交文字 issue。
3. 在 `vpd_skill` 目录，用该项目 Python 环境分别执行下列命令。替换路径、源名称与结果观测 ID。来源是搜索前刚读到的收藏；不能在搜索结果里挑一个出现过的词反填。

```powershell
python -m vpdtest.qk_search_evidence --evidence-dir <本次本地会话目录> --obs-id <结果观测ID> --name "<独立读回的完整名称>"
```

`row_observation=observed` 表示该次保存的搜索页中，输入框的实际文本和一个可完整读取的实体行标题与给定名称一致。已知同名行（包括已在树中但被裁剪的行）、其他形状的同名结果或采集不一致都会阻断。输出的 `row_texts` 只含该行矩形内完整可见的真实文本。标题完整即可继续记录名称，裁剪的可选字段单独计入 `omitted_text_nodes`。当前树不能证明虚拟列表外没有同名对象。退出码 0 表示取到了这条观察，1 表示该行取证受阻，2 表示输入或文件错误。工具固定输出 `favorite_identity=undetermined`、`number_requirement=pending`、`product_verdict=not_evaluated`。

## 如何下结论

| 要报告的内容 | 何时有证据 | 缺项如何记录 |
| --- | --- | --- |
| 名称结果行 | 同一次结果观测中的实际输入框、搜索页与唯一同行均符合。保留结果 obs、行节点编号、同行文字。 | 重名、脏词、裁剪、未识别行或布局变化写明原因，保留首触发现象。 |
| 收藏身份 | 先有本轮独立收藏来源能证明归属和类型，再能将它绑定回这一个结果。例如两端都有同一业务对象的稳定标识，且能核实该标识在相应园区、对象类型下唯一。标识须落在所选实体行的正确字段；同样的字出现在名称或其他字段也不够。 | 只有同名、同层、相似标签或“默认”，均写“身份待判”。预置或改名可准备数据，单凭随机名称或一次搜到不能证明唯一性。独立身份无法证明时不签名称业务通过。 |
| 编号展示 | 独立来源需先给出本轮编号，并能读到同一已辨认对象结果行的对应编号字段。分别记录“源里读没读到”“本行显示什么”“产品是否要求显示”。 | 来源没给编号、行内字段语义不清或产品未定义时逐项待判。邻行编号、结果倒填或把同名当编号均无效。路点字段缺失可能只是该版 UI，当下的 #108 仍需独立要求。 |

### 文字 issue 的最小结果

每个对象一行：对象类型与本轮名称 · 收藏来源 obs / 权属和区分依据 · 结果 obs / 实际输入 / 行内文字 · 同名反例或缺口 · 名称行观察 / 收藏身份 / 编号字段三项各自的结论。图片与树在本机对照，只记 obs ID；需要测试人裁定时注明待补视觉资料及具体争议。

本方法只产生现场取证材料，没有注册生产 target 或新判据。历史树是 1.x 的回归样本，不能替代当前折叠屏记录。#269 的 v4 candidate 仍按四项条件独立执行；此诊断不给它累计重放、通过、审核或晋级。若身份来源在新版本得到稳定验证，再单独评审可执行的名称子范围。[候选资产 #269](https://github.com/amazing-fish/ghost_VPD/pull/269) · [收藏身份 #111](https://github.com/amazing-fish/ghost_VPD/issues/111)
