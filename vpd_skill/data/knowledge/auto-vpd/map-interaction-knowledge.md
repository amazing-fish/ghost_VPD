## 2. 交互规则（实测裁决）

| 操作 | 结果 |
|---|---|
| 地图空白处点击 | 落到 XComponent（可能取消选中/无效果），面板可能残留但控件失效 |
| 地图车位号点击 | 打开车位详情面板（vision 坐标误差 ~40%，不可靠——用搜索代替） |
| 搜索结果行点击 | 打开车位详情面板（确定性 ✓） |
| 搜索结果行"路线" | 直接算路（确定性 ✓，用例2算路步骤用此路径） |
| 常去地点行点击/横滑 | 直接算路（无面板） |
| 面板"收藏"点击 | **无效果（hit-test 被地图 XComponent 吞，DTS 候选缺陷）** |
| 面板标签 chip 点击 | 命中正常但无状态变化（疑似需先收藏） |
| 面板"查看路线" | 发起算路 ✓（同行唯一稳定可交互按钮） |
| 回自车/全览 | 地图视角复位到自车位置 |

## 3. 已固化原子能力（v1.2.0 起注册于 scripts/atoms.py，文档见 atom-registry.md）

- 12 个注册原子：设备/形态/登录前置（device.precheck、app.restart、
  app.relogin_if_needed、vpd.enter）+ 地图（map.pan_random）+ 搜索/面板
  （spot.open_panel_via_search、panel.favorite_hittest、panel.tag_hittest、
  panel.rename_probe、search.route_via_search）+ 终态/清理（assert.not_activated、
  app.back_out）。用例=数据组合（cases/*.json），组合规则见 atom-composition.md。
- `hit_test_click`（flows/case2.py，被 *_hittest 原子复用）— uiRecord 取证式点击
  （DTS 证据链：目标坐标 + 实际命中控件 + 原始事件流）。**已知限制**：uiRecord
  捕获通道间歇性失败（troubleshooting §15）——捕获不到时 hit=None，状态验证照常
  出 BLOCKED 证据，缺陷结论不依赖单次捕获。
- `vision_best_effort` — vision 读图留证（best-effort，网络失败只记 warning）。
- `MAP_SWIPE_REGION[form]` — 形态感知的地图滑动安全区（dual 已两轮 E2E 验证）。
- `rename_probe` 行为（2026-09-28 23:28 run 实测）：面板开着时"更多"不可见——
  原子先 Back 回主页再找；dual 形态"更多"@~(447,1033)，点击仅展开 10 项常去列表
  （10_favorites_expanded.jpeg 留证），仍无 管理/编辑/重命名 入口。
