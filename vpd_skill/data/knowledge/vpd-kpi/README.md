> 来源：`ads-sdk-kpi` 技能（ADS-SDK 维测 KPI 看板数据查询分析器，DataWorks 自助报表
> BI Viewer + Playwright fiber 全量取数），2026-08~09 在 hza_vpd 数据集上的全部验证
> 用例、表结构探明、口径决议与回归判定方法论。这些历史材料与

本目录四份 Markdown 由 `search` 作为背景源材料检索，返回 `unconfirmed_doc` / `unknown`，
供人追溯原时点记录。本仓未接 KPI 取数或 SQL 执行，也未据此增加生产用例覆盖。
K-KPI-001~005、K-IC-001~010 的确认与独立适用性仍沿知识条目和实际运行事实处理。
项目记忆中已提炼为 K-IC-001~010 的冻结规则节保留原文来源，检索由结构化条目承接；
该文档其余工程章节及设备原文中的独有观察继续可检索。

## 对本架构的对应（五类信息映射）

- **knowledge items**：两表 schema/事件语义/30m 法规限制/DAU 稳定性/回归锚点优先级
  已提炼为 items.json 的 K-KPI-001~005；车外对讲冻结业务规则提炼为 K-IC-001~010。
- **历史运行观察**：business-cases 每用例含原时点数字与 SQL，可用于设计后续取证。
  新运行需取得当前数据、明确口径与适用范围，再结合独立确认的产品要求进行判定。
- **执行经验**：回归判定的三锚点优先级（SNAPSHOT 构建时间戳 > 码值首现止步 > 版本
  首现）与"载体版本零失败≠回归通过"纪律，适用于本架构 RSI 经验闭环的候选经验。
- **候选用例**：business-cases 用例 2/3（30601 自检误报、V4.2 埋点零上报）即"线上
  问题→数据验证→结论"的完整范式，可转 KPI 域回归用例。
- **数据可得性**：KPI 数据非实时（T+1 末 ~95%、T+7 ≈98-99%，8/12 管线代际切换）——
  回归用例的取数时点设计必须考虑（K-KPI-004）。
