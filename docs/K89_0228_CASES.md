## 复测与验收

以下命令在仓库 `vpd_skill` 执行：

```powershell
python -m vpdtest case lint TC-QK-240
python -m vpdtest case review TC-QK-240
python -m vpdtest run TC-QK-240 --device hdc:5MT0225B05000904 --authorize vehicle_selection
```

240–249 可逐条用于 informal 诊断；须先核对应现场，运行返回 `action_required` 时立即交接。
它们保留 session 来源的人工审核要求，未经有效人审不进入 suite 或晋级。
判据 unconfirmed 时，即使 `observed_holds=true`、步骤全部完成，也保持 pending；不改写为产品 passed。

每例清理使用现有 stop_app，并检查实际 `stop_check.process_ended=true`，不能只看下发成功。
该检查不证明网络、车辆或用户数据等其他状态已经恢复。
正式验收仍须核对原表完整步骤/预期、独立适用判据、必要人审及当前绑定下的确定重放；本包不代行这些人工决策。
