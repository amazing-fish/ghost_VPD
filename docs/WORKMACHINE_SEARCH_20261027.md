## 最小实现与逐项验收

现有`read`已有唯一定位及measurement，input和目标已有参数替换；缺少读数到本次参数的绑定、断言参数消费及经过校准的收藏集合/空态定位。`qk_fav_item`仍为hypothesis。先补真实AA树，再沿同一执行链做小切片，不增加平行收藏解析框架。

| 验收项 | 可接受证据 |
| --- | --- |
| 收藏名称搜索 | 输入来自本次独立读取的收藏；同一唯一结果行核名称、实体类型及有独立依据的字段。两园区/账号分别重放，不从搜索结果反推期望；同名不同实体、相邻行字段、同号不同名不得拼成通过 |
| 按车位号搜索 | 与名称搜索独立覆盖；使用本次已读到的车位号，不能用名称搜索通过代替。路点缺编号的适用性须由独立字段来源裁定 |
| 空收藏 | 独立明确反证才为not_applicable；树不全、未加载、查不到某个名字为pending，采集/执行异常为error |
| 输入及绑定边界 | 读取失败/歧义不得输入旧值或占位串；运行时名称含引号/正则字符仍按字面量匹配；不覆盖secret；保留源步骤和obs关联 |
| 确定结论与清理 | 已确认且适用的规则才能pass/fail；未确认保留pending。每次记录run/obs、步骤/断言/产品结论及首异常，结束APP后独立核进程结束。新增副作用须按既有授权和清理归属执行 |
