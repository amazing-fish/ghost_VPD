## 工作机使用

更新主线即可取得这两份完整 regression 资产，无须复制家庭机旧 runs，也不因缺失原件重复批准。先运行 `case readiness` 检查既有审核和适用条件；实际执行使用当前设备与真实环境，新运行独立产生结果。现有准入仍会拒绝绑定变化、撤销审核、静态风险不符与当前条件不满足，历史 passed 不会替代本次结果。

## 可移植性验证

`vpd_skill/tests/test_published_regression_assets.py` 使用复制仓库 data 的全新临时工作区、无旧 runs，检查两份资产 regression、有效批准与批量准入；使用离线 replay 生成新运行并检查其独立 run_id 与实际步骤。不把离线 replay 当成新的真机验收。
