# #236 导航定位收敛与资产影响

## 修复与边界

`tab_my` / `tab_car` 不再用无范围的同名文本或 XPath 定位，优先在 `TabBar` 内查找；只有已知窄屏可尝试底部 85%–100% 区域。其他四个导航目标本就限定 `TabBar`，一并加入回归。

这避免「我的」标题与导航同名造成假适配经验，或只有标题时被误当导航进而形成产品失败。选中态仍按现有规则读取可点击祖先，不修改 K-MOT 判据或 expected。

宽屏测试是合成侧栏树，不是真机验收。宽屏未暴露 `TabBar` 时明确未找到，不使用窄屏坐标猜测。普通 `tap` 仍会点击已选中的导航；仅 `ensure_state` 已有到达目标状态后不再导航的语义。本次不实现通用选中短路，不能据此关闭 #236 全部验收项。

## 已有资产的迁移与当前复用状态

定位依赖变化最初使两条 regression 资产的旧审核失效；工作机随后按新定义完成六次实机运行，独立复核后通过现有 CLI 生成新绑定。当前发布内容已包含：

- `TC-HM-S01`：内容哈希 `515054e86da9` 未变，当前依赖 `9c4436c1b914`，三次当前依赖下的通过重放。
- `TC-MOTOR-HM-002`：内容哈希 `b4de659323c5` 未变，当前依赖 `19d7bdc10603`，三次当前依赖下的通过重放。
- 两条均保持 `regression`，审核为 `approved/valid`。没有改判据、弱化断言或手改成熟度。
- 另四条受定位依赖影响的资产仍保持原等级：001/003 为 draft，004/008 为 exploration_record，不随本次批量晋级或重签。

新绑定与当前重放摘要属于仓库资产。另一台机器不需要原机器运行目录即可核对静态绑定并复用批准；`evidence_verification=not_checked` 表示尚未检查本机证据原件，不等于绑定无效，也不代表重新验证过原件。独立复核记录及原文指纹见 [工作机复核](236-tab-scope-workmachine-review.md)。

可移植批准不是无条件适用于任意设备或版本：本次实机证据覆盖已记录的版本及窄屏形态，宽屏侧栏仍未实机覆盖。新执行仍产生自己的步骤、断言和结论，不能继承历史 passed；当前登录条件仍不能靠声明冒充测量。

`test_published_regression_assets.py` 现在验证当前新绑定有效、三次新依赖实机重放、无本机原件的 fresh workspace 可复用及新执行独立判定。旧 stale 负例通过隔离夹具显式构造，不再把发布资产必须过期写死，也不修改真实审核记录。

### 已暴露的既有审核契约差异

`require_review()` 仅在 `review_status.required` 为真且 `valid` 为假时拒绝。在隔离 stale 负例中，探索来源的 S01 被阻止；002 无探索来源，`preflight_batch` 与 `require_asset_review=True` 返回 stale/invalid 但仍允许执行。这个既有行为不等于 002 仍有有效批准；本次没有扩大到修改准入规则。若产品要求所有 regression 资产都强制有效审核，这需要单独修复并补批量入口测试，不能宣称当前所有 stale 资产均被强制阻止。

## 本地证据

- 新增合成树首轮：旧实现 16 失败 / 8 通过；修复后相同 24 项全过。
- 增加漂移回放用例：25 项全过，重名标题不再产出 locator_preference 候选。
- `test_experience.py` 生命周期测试在隔离工作区显式注入旧缺陷，不再要求生产保留坏定位。
- `test_layout.py` 保持窄屏/宽屏定位行为回归。
- 上述定位/机制测试为本地证据；新增实机通过与批准来自链接中的工作机独立复核，不能将两者混称。
