# #262：页顶原生 Row 的滚动语义

## 证据与范围

工作机在五 PR 集成树 `38f0f2b431e36860d7e31baacfceca2bbfbc3ef5` 对照：
页底起跑 `run-20261117-143934-0b44` passed；页顶起跑
`run-20261117-144301-4c96` 在 S3 policy_denied。被审核节点是不可点击 Row，
其路径外副标题含“精选/充电/购车等”。#258 仅处理 List 本体，Row 仍展开全部后代。
本地仅读取 Issue #262 的文字反馈，未取得工作机截图、树或日志原件。

本变更叠加 #258，既不改变候选 within/start/end，也不使用左边缘坐标规避。
仅对已验证 Scroll/List/Grid 范围内的不可点击原生 Row，且其点击语义容器就是
自身（不存在可点击祖先接管）时，检查其自身 text/description 而非所有后代。
路径上真正命中的文字、可点击行/按钮、危险类型、未知表面继续经过已有拒绝。
普通 tap 不传滚动范围，语义不变；Column、Text、Button 等不扩大豁免。
因此后续遇到其他布局结构仍可能阻断，不能把这次修改视作所有不可点击节点均可安全拖动。
