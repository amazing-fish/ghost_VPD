# #245：取消步骤的不适用原因证明

本次仅完善运行时与隔离合成验证，不修改 HM002/S01、生产知识、资产批准或动作权限。正式资产迁移及实机验收仍须单独完成。

- 必需步骤仍保持 critical，取消的后继仍是 not_run，没有 final_obs，不产生 passed 或 verified 覆盖。
- 仅来源是入口 condition_false、没有尝试或恢复，后继操作 when 与其显式断言 guard 完全匹配，且无安全接管时，额外采一次只读观测。新证据记为 applicability_evidence，时间点是业务步骤被取消时、cleanup 之前。
- 断言重算来源与新观测，必须都明确 false，并核对真实 scope、action_epoch 与有效期。来源反证缺失、冲突、过期、动作或身份变化均不豁免。新观测采集错误成为 error，KeyboardInterrupt 不吞掉。
- 只有这个取消步骤的全部必需断言均由上述证据得到 not_applicable，其 required_step_skipped 不确定项才成为 not_applicable。无 guard 的必需后继或额外断言仍保持 pending/not_run，不全局抹掉停止原因。
- cleanup 后的页面变化不推翻先前成立的选支证据；cleanup 自身失败、执行错误、安全警报仍按原逻辑影响整例结论。

适用条件表示观测到的页面场景，不升级为已测得账号登录事实。定位存在只用来选支；产品正确性仍由切换后的页面和选中态独立判定。

代价：明确不适用分支的每个匹配取消步骤多一次只读观测，而非每个断言都采集；其余路径不增加观测。旧运行没有这些证据时维持旧保守行为，不自动重算历史成熟度。嵌套 flow 断言寻址不在本次范围。
