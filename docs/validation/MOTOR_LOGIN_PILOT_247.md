# #247 motor 登录迁移：隔离的两阶段离线 pilot

## 本次交付是什么

`tests/test_motor_login_pilot.py` 在 pytest 临时 APP、临时 policy、临时知识和 Replay 页面中组合既有 Runner、page condition、flow、Params/secret、当前观测与后置判定。它是候选设计的可执行回归，不是可部署的 motor_hm 登录能力；未新增生产 targets/flows/recipe，未改账号或设备，未读取真实凭据。

新增的是 motor 迁移需求的组合证明与负例。底层登录输入、授权、流程与条件机制已经存在，本次不是重新实现这些引擎能力，也没有给 NEXT 校准背书。

## 为什么分两阶段

1. **只读识别**：在当前前台页面取证。目标账号的独立正证存在则直接返回，不要求凭据、不输入、不点击。明确的未登录页面才选择下一阶段；缺证据、相互矛盾、未知身份、其他账号或挑战页停止，不退出或切换账号。合成正证是虚构的专用账号区标记，不是“注册/登录消失”。
2. **独立登录候选 case**：账号和密码都是非条件 flow 的必需 secret。任一缺值由 Runner 现有 preflight 阻塞，连入口点击都不下发。凭据齐备后先重新观察页面，防止第一阶段与第二阶段之间账号/挑战状态改变；进入 flow 的入口点击本身还需当前 needs_login 条件成立，再执行输入、提交。终态必须出现独立的目标账号正证。

若把整个登录 flow 只包在条件里，secret 可推迟到具体 input 时才发现，可能已经导航或输入另一字段。因此这里不为“已登录免凭据”牺牲“任一凭据缺失零下发”，而采用两个独立阶段。

这两个阶段的调度和 `credential_handoff` 仅在测试 helper 中存在，尚不是生产 CLI 的自动入口。第一阶段的只读结果不能长期缓存；第二阶段再次采样，输入/派发仍走现有执行器。

## 真实观察到的交接契约

预检缺 secret 时实际结果为 `blocked`、`env.unmet` 指明缺失的环境变量引用，零派发；**当前并没有自动产生 `verdict.action_required`**。测试明确保留这个事实，没有补造该字段。

测试调用方从 `env.unmet` 提取缺失引用，明确提示“在本机配置所列密钥，再重新观察当前页面；不要续发旧步骤”。这只是待迁移调用方的呈现范例。真实凭据由本机既有密钥机制提供，不通过 issue、报告或测试资料收集。

## 回归边界

- 明确目标账号已就绪且没有凭据：只读返回、零派发。
- 缺账号、缺密码、两者均缺：blocked、零派发，列出缺失引用。
- 明确未登录 → 密码 flow → 独立账号正证：合成通过；不算 VPD 业务通过。
- 入口消失但到了未知页、挑战页、错误页或另一账号：不通过。
- 挑战/另一账号页面同时出现注册入口：不能选择登录。
- 两阶段间，或第二阶段 RECHECK 后至 flow 首动作前，变成已登录、另一账号、挑战或未知：重新观察后停止，零派发。
- 观测失败不伪装成“不涉及”；无 account_state 授权不能执行。
- 仅验证合成秘密不出现在 run.json/events.jsonl 明文中，不据此承诺真实 UI 树或截图永远不会显示密码。真实安全输入控件仍须现场确认。

当前证明两阶段之间以及 flow 首次入口点击前的重新观察；尚未实现输入过程中挑战突现时的提交前专用状态重验，也未覆盖真实协议勾选，不能据此部署登录。

测试不含 logout、验证码发送、账号安全验证写操作、修改密码或车辆动作。没有用“退出登录”入口证明账号身份。

## 最小现场补证清单（不需要凭据内容）

在现有未登录设备上读取当前页面结构，不要求主动退出账号造反例：

1. NEXT `app.huawei.hmos.motor` 的我的页注册入口、账号方式选择、账号输入、手动输入分支、密码输入及提交控件的实际类型、标识、可见范围、所属窗口/应用和遮挡情况。Android `app.huawei.motor` 的旧 XPath 只能作路径来源，不能标成 NEXT 已校准。
2. 当前目标账号的独立正向辨识区域及另一账号/未登录的反证；证明它来自当前页面，而非旧观测、入口缺失或 logout 文本。报告只需结构与判定方法，不收账号密码。
3. 协议已勾选/未勾选、身份验证、验证码、登录错误和重复登录提示的分支结构，尤其入口与挑战/另一账号信息同时存在的混合页面。本 pilot 未实现协议交互或挑战处理；遇到它们交接，不猜“同意”按钮。
4. 登录过程中跳转的 bundle、页面生命周期、输入后的安全键盘/遮挡、提交前再次观察与提交后终态；确认未成功前不能运行依赖业务。
5. 同账号登录是否挤下其他测试机，明确设备协调，再做一次受控登录验证；不能自动登出另一设备。

校准完成后才登记生产候选并在真实当前定义下复测/独立审核，和新资产绑定一起交付。#234 负责事实观测，#245 负责导航场景适用性，两者不必等待本登录 pilot 完成；25条账号前置中仅5条属于 motor，其余20条属已有登录能力的乾崑。
