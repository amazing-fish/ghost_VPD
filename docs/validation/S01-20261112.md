## 换机后怎么办

本文不修改仓库用例成熟度、审批记录、经验库或权限，也不授予另一台机器批量执行资格。家庭机 local regression 不等于工作机已验证。

当前代码会在 agent 审核有效性检查时重新读取原件。只同步本地资产 JSON 而没有原件，记录仍可能显示 regression 和两次历史通过，但 review 会变为 stale / valid=false，review-route 为 evidence_needed，批量准入阻止执行。这是证据不可用，不是需要用户再次为同一定义签字。

异机需要取得经允许交接且完整可验证的证据，或按当前定义、现行动作权限重新取证并独立复核。不要为省事关闭原件校验；不要把本摘要或 hash 当作原始现场。此次同步仅文档，未设计新的证据共享服务。
